# foo_speaklyrics

foobar2000 LRC lyric speaking component.

This Gitee repository only hosts public component installation packages.
The source code is maintained on GitHub:

https://github.com/zjmxczhy/foo_speaklyrics

## Downloads

- `foo_speaklyrics.fb2k-component`: combined package
- `foo_speaklyrics-x64.fb2k-component`: x64 foobar2000
- `foo_speaklyrics-x86.fb2k-component`: x86 foobar2000

Install the matching `.fb2k-component` package from foobar2000:

```text
File -> Preferences -> Components -> Install...
```

Checksums are listed in `SHA256SUMS.txt`.
